# Extension-ExcellentEconomy
ExcellentEconomy plugin DataExtension for Plan

<hr>

Just shows all the ExcellentEconomy's currencies' stats on the Plan dashboard.

Has a custom page for it & each player has a tab that shows their balance for each currency.
